# Angels AI — Website

Roadmap V4's visual website shell for Angels AI: choose dance skills, add a
song and character artwork, then create a beat-synced dance.

This iteration is intentionally presentation-only. Uploads, music analysis,
motion blending, character rendering, accounts, and persistence belong to
later roadmap steps.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm test
```
